3. **MAJOR — Scheduler `pool.py` does not enforce the 16-rank physical core budget across concurrent jobs.**
   - **File & Line**: [`pool/pool.py:30-41`](file:///home/azan/paper6_t6_work/pool/pool.py#L30-L41), [`WORK-ORDER-2026-09-24.md:209-211`](file:///home/azan/paper6_t6_work/scratchpad/T6_repo/cfd_handover/WORK-ORDER-2026-09-24.md#L209-L211)
   - **Details**: Work order section 6 mandates: *"The host has 16 physical cores. Plan against 16, not the 32 that nproc reports. Total solver ranks across all concurrent jobs <= 16."* In [`pool.py`](file:///home/azan/paper6_t6_work/pool/pool.py#L30), `used` ranks are accumulated, but the admission loop never checks `if used + j["ranks"] > RANKS: continue`.
