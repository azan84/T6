# U3D jet-state check (2026-10-01, written BEFORE any result of the re-run)
Question: were the U3D 3D levels (S50, S25A, S12A, S25B, S12B; fields deleted) on the axisymmetric or the wall-deflected steady state of the sten70 case (report sec. B3)?
Method: rebuild level S50 with the deposited tooling (u3d/make_sten70_fine_stl.py, make_sten70_mesh.py S50, build_sten70_case.py S50, U3D_END=3000 as the original), run it (8 ranks, --bind-to none: the host is shared with another project's 8 serial jobs; timing is not a result), keep the final fields, compute the jet offset (|U_x|-weighted centroid, jet_offset.py: x = 35..80 mm) and the FFR at x = 56.5 mm (last-100 mean).
Decision rule (fixed now):
 (a) re-run jet offset <= 10 um at x = 50 and 56.5 mm AND |FFR - 0.793362| <= 1e-4 -> the original S50 was on the axisymmetric state (same value on the same state); evidence for the other levels stays indirect (families A/B and wedge agreement), but the level that controls the observed order is verified.
 (b) re-run deflected (offset >= 30 um) -> report its FFR; if it differs from 0.793362 by > 5e-4, the original S50 was on the OTHER (axisymmetric) state; then run S50 again from a perturbed/mapped symmetric start is NOT done automatically (decision for the study lead).
 (c) symmetric but |FFR - 0.793362| > 1e-4 -> mesh-realisation effect larger than expected: report, no conclusion on the state of the original.
 (d) anything else (10-30 um, unsettled) -> inconclusive, report.
Then, if time allows and (a) holds: the same for S25A (U3D_END=4000).

## Dated extension, 2026-10-03 (written BEFORE any Task B run; in answer to the GPT-5.6 Sol and Gemini 3.8 Flash pre-run audits of the Task B tooling)
Scope: work order 2026-10-03 section 3 (Task B): the levels S25B, S12A and S12B, re-run at 8 ranks on regenerated meshes with the original budgets (S25B 4000, S12A 6000, S12B 3000 iterations), fields kept. The decision rule of this document applies unchanged to each level L with its own ORIGINAL FFR (returns/2026-09-26/U3D_sten70.csv): S25B 0.791197, S12A 0.790308, S12B 0.790418 (S50 0.793362 and S25A 0.791103 were done on 2026-10-02: both rule (a)).
Rules per level: (a) re-run jet offset <= 10 um at x = 50 and at x = 56.5 mm AND |FFR - FFR_orig| <= 1e-4 AND the run is SETTLED -> the original level L is verified on the axisymmetric state; (b) deflected = jet offset >= 30 um at x = 50 OR at x = 56.5 mm (either station); report its FFR (if it differs from FFR_orig by > 5e-4 the original was on the other state); no automatic restart from a perturbed state; (c) offsets <= 10 um but |FFR - FFR_orig| > 1e-4 -> mesh-realisation effect, no conclusion on the state of the original; (d) anything else (10-30 um at either station, or UNSETTLED) -> inconclusive.
SETTLED is the criterion of u3d_design v2.4 (u3d_analyse.SETTLE_DRIFT, SETTLE_BAND): at least 500 iterations, |mean(second 250 of the final 500) - mean(first 250)| <= 2e-4 in FFR and the last-100 FFR band <= 1e-4. An unsettled run can never be classified axisymmetric or deflected (rule (d)).
After the three levels: if all five levels (S50, S25A, S12A, S25B, S12B) are axisymmetric under rule (a), U3D is final (work order D9); GCI21 of both zone families is recomputed with the re-run values where they reproduce the originals within 1e-4 (they are then the same numbers). If any level is deflected, the ladder is reported per state and the states are not mixed.
Equivalence statement: the re-runs use 8 ranks on regenerated cfMesh meshes (the originals: 16 ranks on the original meshes); the cell counts equal the original ones; the evidence about the ORIGINAL state is the FFR reproduction within 1e-4 together with the jet state, not decomposition or mesh identity. Order: S25B, then S12A, then S12B, strictly one after the other (RAM).
