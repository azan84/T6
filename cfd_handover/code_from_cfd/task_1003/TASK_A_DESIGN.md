# Task A (D7 sensitivity test), design v1, written 2026-10-03 BEFORE any Task A solve (pre-registration)
Question (work order sections 1 D7, 2): does re-meshing the scan-14 baseline throat zone at 12.5 um change the measurement-probe FFR by less than U3D = 0.00055 (provisional)?
Cases (all scan-14 baseline package, resistance mode, production template of Task C with the D8 probes, 16 ranks as the returned solve, budget 3000 iterations, fields kept):
- A1: throat zone 12.5 um, +-4 mm (6,241,438 cells), mesh m1/mesh/baseline_D7_12p5.
- A2: throat zone 12.5 um with the zone-B interface shift (-3..+5 mm) (8,308,794 cells), mesh m1/mesh/baseline_D7_12p5_zoneB. Run because A1 still has flagged face-tets within 2 mm of the throat (0.698 mm; D4 FAIL in both variants; work order: try the shift, report both, do not search beyond).
- Optional control A0 (only if time/RAM allows, after A1/A2): the rebuilt production mesh (25 um, m1/mesh/baseline_v2, identical gates to the returned mesh) re-solved with the same template: measures the reproducibility of the returned value on a regenerated mesh (cfMesh is not bitwise reproducible).
Decomposition: 16 ranks (scotch), as in the returned solve (audit finding: do not change decomposition and resolution at the same time).
Reference value (audit finding): the returned measurement-probe value is p_over_Paorta = 0.8697574904997768 (returns/2026-09-26/M1_probes_baseline_resistance.csv, row p011 measurement, time 3000, section area 3.3695557 mm2, section-averaged pressure by connected-section pullback of the reconstructed iteration-3000 fields). The new value is computed by the SAME method (pf/m1_probes.py on the reconstructed iteration-3000 fields, p011) and cross-checked against the D8 measurementP monitor at iteration 3000. Statistic: DeltaFFR = FFR_new(p011, iteration 3000) - 0.869757490 where FFR = p_over_Paorta at the measurement probe (the P_aorta-normalised section pressure, the quantity the 3D-vs-0D comparison uses); in kinematic units the same difference (P_aorta = 11998.98 Pa).
Acceptance (work order D7, unchanged): PASS WITH DEVIATIONS D2/D3/D4+D7 if |DeltaFFR| < 0.00055 for the variant(s) solved; if every flagged entity of a variant lies >= 2 mm from the throat and the measurement probe it is a plain PASS of D4; if |DeltaFFR| >= 0.00055 M1 fails for the lesion cases and the section 9 fallback opens. Both variants are reported; no repair of the surface.
Settledness: fixed full budget (D8). Solution state reported: iterations, final residuals, flow bands of the outlets, mass imbalance, BC error (resistance mode), all as the returned solve.
Flow-state diagnostic (pre-registered, replaces the straight-axis script of sten70, which is not applicable to a curved lumen): on the reconstructed iteration-3000 fields take the connected centreline-normal sections of the main (lesion) vessel every 1 mm from throat+2 mm to the measurement probe p011, bounded to the vessel (as the Task C bounded planes); per section: area-equivalent radius r_eq, flux-weighted centroid of the axial velocity, offset of that centroid from the section area centroid divided by r_eq (signed in the local frame (normal, binormal)), and its direction. Report the profile offset/r_eq(s) for each variant (and A0 if run). The returned solve's own value at p011 is 0.0901 (M1_probes_baseline_resistance.csv centroid_offset_over_req, a different quantity: pressure-section centroid versus section area centroid; do not compare). Classification: the profiles of the variants are compared with each other: STATES AGREE if max over s of |offset/r_eq(A1) - offset/r_eq(A2)| <= 0.03 and |DeltaFFR_A1 - DeltaFFR_A2| < 0.00055; otherwise STATES DIFFER (reported; no claim of bistability without a two-state restart demonstration, which this task does not include). The sten70 two-state finding is NOT assumed to apply to this lumen.
Resources: about 2.2 GB RAM per million cells (A1 about 14 GB, A2 about 18 GB): the two are run one after the other; each case about 3-5 h on 16 ranks; processors kept until post-processing is finished; disk about 2.5 GB per case plus reconstructed time directories.
Outputs: M1_D7_sensitivity.csv (one row per variant: cells, strict checkMesh counts, D3/D4 min distances, FFR at p011 and throat, DeltaFFR vs the returned value, outlet flows, converged flags, flow-state diagnostic summary, wall-clock, RAM), M1_geometry_gates_D7-2026-10-03.csv (M1_geometry_gates.csv format, dated), one paragraph in returns/2026-10-03/NOTE.md, report subsection, figures (wall pressure render, section pressure along the vessel, centroid-offset profile, mesh close-up).
