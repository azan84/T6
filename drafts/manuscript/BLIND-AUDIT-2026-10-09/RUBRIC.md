# Blind audit rubric (2026-10-09)

Score every dimension 1–10 (10 = exemplary for a top-10% JBHI paper; 7 = acceptable with minor revision; 5 = major revision; ≤3 = reject-level).
Also give pass / warn / block for the same dimension (block = must be fixed before acceptance).

| Code | Dimension |
|------|-----------|
| S1 | Novelty and contribution |
| S2 | Methodological rigour (design, model, statistics) |
| S3 | Claims supported by evidence (no overreach) |
| S4 | Domain / physiological accuracy |
| S5 | Internal consistency (numbers text vs tables vs figures vs supplement) |
| S6 | Clarity, structure and readability |
| S7 | Venue fit (IEEE JBHI) and health-informatics relevance |
| S8 | Reproducibility and transparency |

Then: overall score /10, and a recommendation: accept / minor revision / major revision / reject.
