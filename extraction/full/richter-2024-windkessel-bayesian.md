# richter-2024-windkessel-bayesian

## Bibliographic
- Title: Bayesian Windkessel calibration using optimized 0D surrogate models
- Authors: Jakob Richter, Jonas Nitzler, Luca Pegolotti, Karthik Menon, Jonas Biehler, Wolfgang A. Wall, Daniele E. Schiavazzi, Alison L. Marsden, Martin R. Pfaller
- Year: 2024 (arXiv:2404.14187v2 [cs.CE], 29 Jul 2024)
- Venue: arXiv preprint (not yet journal-published at time of this text)
- Affiliations: Stanford Pediatrics/ICME, TU Munich (Institute for Computational Mechanics), Notre Dame (Applied & Computational Mathematics and Statistics)
- DOI: N/A (preprint)
- Code URL: svZeroDSolver and svSuperEstimator, both cited as open-source (github links not given verbatim in extracted text, but stated "open-source nature of all software and data used in this work")
- Data URL: Vascular Model Repository (72 publicly available models), cited [46]

## Problem & claim
- Task: Bayesian calibration of three-element Windkessel outlet boundary-condition (BC) parameters θ from noisy clinical observations, using a 0D lumped-parameter surrogate that is itself optimized against one 3D simulation, so that Sequential Monte Carlo (SMC) — which needs "thousands of model evaluations" — can be run cheaply on the 0D surrogate instead of the 3D model.
- Central claim (quoted, Abstract): "We only evaluate the 3D model once for an initial choice of BCs and use the result to create a highly accurate zero-dimensional (0D) surrogate. We then perform Sequential Monte Carlo (SMC) using the optimized 0D model to derive the high-dimensional Windkessel BC posterior distribution. Optimizing 0D models to match 3D data a priori lowered their median approximation error by nearly one order of magnitude in 72 publicly available vascular models."
- Two "novel techniques" claimed (quoted, Introduction): "First, we present a fast deterministic optimization method to yield a highly accurate 0D model from 3D data. Second, we use the 0D model to predict the sought posterior distribution of the BC parameters given noisy observations."

## Method
- Two-run workflow (Fig. 2): Run 1 — SMC on a **geometric** 0D model M0D(θ, α_b), where branch parameters α_b (R, L, C, S per Eq. 17) are derived purely from 3D geometry (radius, length, wall properties), yields a first posterior and a MAP point estimate θ_MAP. Run 2 — one 3D simulation is evaluated at θ_MAP: M3D(θ_MAP). Its pressure/flow solution vectors (y, ẏ) are used to fit an **optimized** 0D model via Levenberg-Marquardt (LM) least-squares (Eq. 24-26), producing optimized parameters α̂ for both BloodVessel and (newly identified) BloodVesselJunction elements — junction parameters are *not* derivable from geometry alone and are zero in the geometric model. A second, independent SMC run is then performed on the optimized 0D model M0D(θ, α̂) to get the final posterior p0D(θ|y_obs, α̂).
- Verbatim on the core fitting step (Q-C): "In this work, we propose a deterministic least-squares procedure to optimize a 0D model to match an initial 3D model. Our algorithm optimizes all 0D parameters in the model, i.e., resistances, inductances, capacitances, and non-linear stenosis factors." And: "Solving an inverse problem, we infer 0D model parameters α̂ that optimally (in the least-squares sense) approximate given 0D solution vectors y and ẏ. In this work, y is extracted from a 3D model M3D evaluated at the parameter set θ_MAP."
- Optimizer: Levenberg–Marquardt, analytic Jacobian per element, tolerances tol_grad=1e-5, tol_inc=1e-10, max 100 iterations (Appendix B.2).
- Solvers: 3D — SimVascular's svSolver (finite element, incompressible Navier-Stokes, rigid walls); 0D — the authors' own svZeroDSolver (C++/Eigen), used for both forward 0D solves and the inverse LM fit.

## Data
- 72 publicly available vascular models from the Vascular Model Repository (aorta, aortofemoral, coronary, pulmonary), reused from Pfaller et al. (prior paper), with existing Windkessel BC parameters θ_VMR "calibrated in prior studies." Anatomies include normal, aortic coarctation, Kawasaki disease, single-ventricle disease, Marfan syndrome, AAA, pulmonary hypertension, "and others."
- No patient cohort of the T6 kind; no invasive FFR; no clinical decision threshold. Observations y_obs for the demonstration case (model 0104_0001, an 11-year-old female with aortic coarctation) are "artificially created based on one 3D simulation," not real clinical measurements.

## Evaluation
- Section 3.1.1 (parameter identifiability, no 3D-0D discrepancy): mean R² across all 72 models/branches = 1.0 for R, L, C; R²=0.95 for stenosis coefficient S. "three coronary models stagnated at residual norms slightly above the tolerances."
- Section 3.1.2 (optimizing to real 3D data, Eq. 28): "the optimization improved the maximum approximation errors for pressures ϵP,max and flow rates ϵQ,max in 71 out of the 72 models." "Only the coronary model 0186_0002 performed slightly worse after optimization. For this model, the junction between the aorta and the coronary arteries could not be calibrated properly." "the median error was reduced from 5.6% to 0.6% for pressure and 12.3% to 1.4% for flow following optimization" — i.e., roughly an order-of-magnitude reduction, matching the abstract's claim.
- Section 3.1.3 (generalization across BC parameter space θ, NOT across geometry): tested on 3 models (one aortic coarctation, one aortofemoral AAA, one pulmonary), each with 50 BC-parameter variants (±20% uniform multiplicative perturbation of flow/resistance/capacitance) from a prior dataset (Pegolotti et al.). Cross-validated 50× per model (fit on one θ_i, test on the other 49): "the validation error is equal to or slightly larger than the training error," confirming the 0D surrogate generalizes well across BC parameter changes for a **fixed geometry** — this is BC-space generalization, not geometry-space generalization.
- Section 3.2 (Bayesian calibration cost, single case, model 0104_0001, 5 outlets/5 parameters): "The parameter estimation for the SNR = 100 case took a bit over 24 h, where 1.5h was spent on the first SMC run (with 210,000 0D evaluations), 21.5 h on the 3D simulation and 1.5 h on the second SMC run. The LM calibration took only 20 s." I.e. one 3D run per patient (~21.5h dominates wall-clock), LM fit itself is nearly free (20s), and running LM optimization across all 72 models took only 79s total on a single core.
- Section 3.2.3 (0D-vs-3D posterior validation, a separate expensive check, not part of the deployed method): "Performing all 100 3D simulations took nearly 800 hours on two 64-core AMD EPYC 7742 CPUs, while the 100 0D simulations were completed in less than a minute on a single core." The optimized 0D posterior "clearly encapsulates" the 3D posterior; the geometric (unoptimized) 0D posterior "completely fails to provide a viable surrogate for the 3D posterior."

## Reproducibility
- Code: svZeroDSolver and svSuperEstimator both stated open-source; SMC implementation based on Python package `particles`. Data: all 72 models from the public Vascular Model Repository.
- Nothing blocking reimplementation identified in the extracted text; hardware used is named (Stanford Sherlock cluster, Intel Xeon Gold 5118; SDSC Expanse; AMD EPYC 7742 for the 100-3D-run validation).

## Limitations
- Quoted (Section 4): "there are still some deviations between the optimized 0D models and the 3D models, especially for pulmonary models." "The 0D model optimization has been performed using one cardiac cycle of a periodically converged simulation. Future studies should investigate whether the amount of 3D data necessary to sufficiently inform the 0D model optimization can be further reduced." "We evaluated the proposed calibration framework on artificially created measurement data... further work could focus on using subject data." "We limited our investigations to rigid-wall 3D models of the vasculature."
- Not admitted, but evident from the text: the method's central assumption is a **fixed geometry** between the one 3D run and every subsequent 0D use. No experiment perturbs or changes the 3D geometry itself between the 3D run and the 0D optimization/SMC steps — geometry is held constant throughout Sections 3.1 and 3.2; only the Windkessel parameter values θ are varied or treated as uncertain.

## Openings
- Explicit future work: incorporating more than one 3D simulation for higher-accuracy calibration (multi-fidelity); an expectation-maximization treatment of the 0D parameters α as latent variables jointly optimized with θ; applying the framework to compliant-wall and to real subject/clinical data instead of artificial observations.
- Unresolved for T6's purposes: the paper never asks or answers what happens to the optimized 0D surrogate (or to the Windkessel BC posterior derived from it) if the **underlying 3D geometry changes** (e.g., a different/erroneous segmentation of the same patient) — the single 3D run that anchors the whole calibration is treated as ground truth, not as a possibly-wrong reconstruction.

## Key references
- Pfaller et al. — source of the 72-model dataset and the geometric 0D model formulation (BloodVessel RLCS elements, Eq. 17) reused here.
- Pegolotti et al. — source of the 50-variant BC parameter perturbation dataset used for the generalization study (Section 3.1.3).
- Tran et al.; Menon et al. — prior derivative-free Windkessel/0D-parameter optimization work for coronary hemodynamics, cited as less complete ("only resistances were adapted... to match key 3D outputs within 10%") than this paper's full-parameter LM optimization.
- Pant et al. — prior unscented-Kalman-filter Bayesian Windkessel calibration, the closest prior Bayesian-calibration precedent, limited to approximately-Gaussian posteriors.

## T6 targeted questions

- **Q-A geometry perturbation**: NOT REPORTED as a geometry perturbation study. The paper perturbs/samples only Windkessel **parameter values** θ (resistance, capacitance, flow) — not the 3D lumen geometry itself. The "72 publicly available vascular models" and the 50-variant BC-parameter cross-validation (Section 3.1.3) test generalization of the fitted 0D surrogate across different anatomies and across different BC parameter draws, respectively, but no experiment re-segments, dilates/erodes, or otherwise perturbs the lumen surface of any single geometry and re-runs the calibration. There is no SYNTHETIC or REAL geometric-disagreement magnitude reported anywhere in this paper.

- **Q-B decision flip**: NOT REPORTED. No FFR, no 0.80 cutoff, no diagnostic reclassification of any kind is discussed. The clinical framing is limited to pressure/flow prediction confidence and posterior uncertainty for treatment-decision support in the Discussion ("the uncertainty in the model prediction can be taken into account while making the clinical decision of whether to intervene or not," re: aortic coarctation), with no quantitative flip/reclassification rate.

- **Q-C BC tuning**: Central method of the paper. The 0D surrogate is fitted from **exactly one 3D simulation per geometry**, evaluated once at the MAP Windkessel parameter estimate θ_MAP from a first (geometric-0D-model) SMC run. Fitting is a deterministic least-squares (Levenberg-Marquardt) match of all 0D element parameters (R, L, C, S per branch, plus previously-unavailable junction parameters) to the 3D solution's pressure/flow time series, using the *same* discretized residual equations as the forward 0D solve (Eq. 18, 24-26). Verbatim: "We only evaluate the 3D model once for an initial choice of BCs and use the result to create a highly accurate zero-dimensional (0D) surrogate." Cost: the 3D run itself (~21.5 h wall-clock for a full cardiac-cycle pulsatile solve on the demonstration case) dominates; the LM fit itself is near-free (~20s per model, 79s for all 72 models). **Whether the fit must be redone after a geometry change is NOT REPORTED / NOT TESTED** — every experiment in the paper (Sections 3.1 and 3.2) holds the 3D geometry fixed and varies only θ (the Windkessel BC parameters); no experiment re-segments or otherwise alters the lumen and re-fits. Logically, because α̂ is fitted to a 3D solution computed ON a specific mesh/geometry, and because the geometric 0D model's own branch parameters α_b (Eq. 17) are explicit functions of local radius r and length l, a geometry change would be expected to require a fresh 3D run and a fresh LM fit — but the paper neither states nor demonstrates this; it is inferred from the method's structure, not asserted in the text.

- **Q-D fidelity / quantity**: Hybrid 0D/3D: one 3D Navier-Stokes solve (svSolver) anchors an otherwise-0D pipeline (svZeroDSolver, lumped-parameter RLCS network per branch plus junction elements). Outputs are bulk pressure and flow rate at LPN node points and at the 3D model's outlets/inlet — no spatially-resolved 3D field quantity (no WSS, no OSI) is computed or discussed anywhere in this paper.

- **Q-E data**: 72 public Vascular Model Repository geometries (aorta, aortofemoral, coronary, pulmonary; various pathologies). No dedicated coronary-only cohort; coronary models are a subset of the 72 (exact count NOT REPORTED, though at least "three coronary models" and model "0186_0002" are named as the ones with optimization difficulties). No clinical/patient outcome data; no invasive FFR; observations used for the Bayesian-calibration demonstration are synthetic ("artificially created based on one 3D simulation").

- **Q-F meshing**: NOT REPORTED. The paper starts from already-available, already-meshed public geometries (Vascular Model Repository); no segmentation-to-surface-to-volume meshing pipeline, and no robustness test on poor/broken/topologically-incorrect geometry, is discussed anywhere.

## THREAT assessment

**Verdict: METHOD.**

Richter et al. (2024) does not do anything T6 claims as new. It contains no real- or synthetic-disagreement-derived geometric error ranking (Q-A is entirely absent), no FFR/decision-flip analysis of any kind (Q-B absent), and — most importantly for the headline BC-absorption hypothesis — it never perturbs geometry at all, so it cannot and does not test whether BC re-tuning masks or absorbs geometric/topological error. Every reported generalization result (Section 3.1.3, the 50-variant cross-validation) holds the 3D geometry fixed and varies only the Windkessel *parameter values* θ, which is a different axis from T6's question (does re-tuning θ compensate for a *wrong geometry*?). What it does offer T6 is a concrete, quotable METHOD for exactly the BC re-tuning step T6's protocol needs: a deterministic least-squares (Levenberg-Marquardt) procedure to fit all 0D Windkessel/branch/junction parameters to a single 3D (or, by direct analogy, single reduced-order) simulation's pressure/flow output, at near-zero marginal cost once that one reference simulation exists (~20s LM fit vs ~21.5h for the anchoring 3D run in the demonstration case), together with a Bayesian (SMC) treatment of the resulting parameter uncertainty. This is directly reusable for T6's Protocol-C BC-retuning step and for the "one equation, one unknown" identifiability concern flagged in STUDY-PLAN.md §8: the paper's own identifiability check (Section 3.1.1, more observations/timepoints than free parameters, R²≈1.0 for R/L/C) is a template for showing a retuning protocol is not trivially exact. It is SUPPORT, not a competing claim, and leaves T6's core three novelty axes (real-disagreement magnitudes, decision-flip ranking by error type, and geometry-perturbation-then-BC-retune absorption test) completely untouched.
